## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately to the maintainers. Do **not** open a public GitHub issue for
security-related reports.

Please include:

- A description of the vulnerability
- Steps to reproduce
- The version / commit affected
- Any suggested mitigation

We will acknowledge your report within a reasonable timeframe and work with
you on a coordinated disclosure.

## Supported Versions

Only the latest released version is actively supported with security fixes.
